# Hangman Game

A simple Hangman game built with **React**. Guess the hidden word by selecting letters before you run out of attempts.

## Features

- 🎮 Random word generation
- 💡 Hint for each word
- 📝 Multiple categories (Fruits, Countries, Household Items)
- ⭐ Score tracking
- 🖼️ Hangman image progression
- 🔄 Play again by starting a new game
